# Bhagyajyoti | Portfolio

Personal portfolio website for Bhagyajyoti, a Full-Stack Developer and Information Science student at Nitte Meenakshi Institute of Technology (NMIT), Bengaluru (graduating 2027).

Live sections: Hero, About, Skills, Projects, Certifications (with AI-based upload), and Contact.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## Features

- Responsive single-page layout with smooth navigation
- **About** — background and career focus (backend engineering)
- **Skills** — grouped by Backend, Frontend, etc.
- **Projects** — showcases:
  - [CafeBook](https://github.com/Bhagyajyoti-123/CafeBook) — full-stack café booking and wallet management system (Spring Boot, MySQL, REST API, Auth)
  - [RoleLedger](https://github.com/Bhagyajyoti-123/RoleLedger) — role-based access control system (Spring Boot, RBAC, JWT, Security)
- **Certifications** — upload a certificate (image or PDF) and an AI-bar reads/extracts the details automatically
- **Contact** — direct contact section

## Project Structure

```
portfolio/
├── index.html   # Page structure and content
├── style.css    # Styling
└── script.js    # Interactivity (nav, certificate upload/AI parsing, form handling)
```

## Getting Started

No build step or dependencies required.

1. Clone the repo:
   ```bash
   git clone https://github.com/Bhagyajyoti-123/portfolio.git
   ```
2. Open `index.html` in your browser.

   Or serve it locally:
   ```bash
   cd portfolio
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

## Deployment

Since this is a static site, it can be deployed directly on GitHub Pages, Netlify, or Vercel with no configuration.
